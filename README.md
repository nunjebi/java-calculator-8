# java-calculator-precourse

## 구현 목록
- [x] **입출력 처리**
  - 문자열을 입력받음. `덧셈할 문자열을 입력해 주세요.`
  - 입력받은 문자열에서 구분자를 기준으로 분리한 각 숫자의 합을 출력.
  - 입력이 없을 경우 출력은 `0`
  - 출력은 `결과 : "합"`
- [x] **기본 구분자(`,`, `:`) 파싱**
  - 입력받은 문자열에서 구분자를 기준으로 분리.
- [x] **커스텀 구분자 파싱**
  - 기본 구분자 외에 커스텀 구분자가 지정된 경우에 해당
  - 커스텀 구분자는 문자열 앞부분의 `//`와 `\n` 사이에 위치하는 문자.
- [x] 예외 처리
  - 잘못된 값을 입력할 경우 `IllegalArgumentException`을 발생시킨 후 애플리케이션을 종료시킴.
  - 숫자가 아닌 문자가 존재할 경우
  - 분리된 수가 `음수`나 `0`이 존재할 경우
  - 시작이 `//`, 그러나 커스텀 구분자가 존재하지 않거나 문자가 아닌 문자열인 경우
