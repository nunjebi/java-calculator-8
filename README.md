# java-calculator-precourse

## 구현 목록

- [x] **입출력 처리**
  - 문자열을 입력받으며, 해당 문자열을 이용하여 수를 구함.
- [x] **문자열에서 쉼표와 콜론을 처리**
  - 처리하고 남은 수를 모두 더한 후 출력.
- [x] **커스텀 구분자를 처리**
  - 문자열의 시작이 `//`인 경우 커스텀 구분자(문자)가 포함된 문자열로 구분하여 처리.
- [x] **잘못된 값을 입력할 경우 `IllegalArgumentException`을 발생시킨 후 애플리케이션 종료하도록 처리**
  - 숫자가 아닌 문자가 존재할 경우
  - 음수나 0이 있을 경우
  - 시작이 `//`, 그러나 커스텀 구분자가 존재하지 않거나 문자가 아닌 경우
  - 개행 문자 이후 문자가 존재하지 않을 경우
