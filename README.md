# java-calculator-precourse

## 구현 목록
- [x] **입출력 처리**
  - 문자열을 입력받으며, 해당 문자열을 이용하여 수를 구함.
- [x] **문자열에서 쉼표와 콜론을 처리**
  - 처리하고 남은 수를 모두 더한 후 출력.
- [x] **커스텀 구분자를 처리**
  - 문자열의 시작이 "//"인 경우 커스텀 구분자(문자)가 포함된 문자열로 구분하여 처리.

## 구현 예정 목록
- [x] **입출력 기능 구현**
  - '덧셈할 문자열을 입력해 주세요.' 및 '결과 : x'.
- [x] **문자열에서 쉼표와 콜론을 처리하여 숫자를 추출**
- [x] **추출된 수의 합을 구하기 및 출력**
- [x] **커스텀 구분자가 포함된 문자열을 처리**
  - '//'와 '\n' 사이에 위치하는 문자를 커스텀 구분자로 사용. ex)'//;\n1;2;3'일 경우 세미콜론이 커스텀 구분자이며, 출력은 6.
- [ ] **잘못된 값을 입력할 경우 IllegalArgumentException을 발생시킨 후 애플리케이션 종료하도록 처리**
  - 음수 포함, 커스텀 구분자가 존재하지 않을 경우, 개행 문자 다음이 없을 경우..
